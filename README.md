# betterLD

> 面向 [LinuxDo](https://linux.do/) 的零依赖 Manifest V3 浏览器扩展：美化原生主题列表，提供手动真实网页预览、树状回复与可配置背景。

全部代码为原生 JavaScript / CSS / HTML，无框架、无打包器、无运行时依赖。

当前版本：**[v0.2.5](https://github.com/xMuelsysex/betterLD/tree/v0.2.5)**。本轮接入原生解决方案与无连线系统事件，支持跳楼后的双向连续加载、向上提前预载，改进限流重试、缺帖恢复与新回复排版；完整记录见 [更新日志](CHANGELOG.md)。

## 功能

| 区域 | 改造内容 |
| --- | --- |
| 首页信息流 | Material 3 原生主题行：保留排序、分页、分类标签、未读和置顶；增加紧凑作者/头像/活动时间/参与者/回复/点赞/浏览、已看、稍后再看与操作菜单。旧阅读卡设置自动归一为原生列表 |
| 搜索结果 | 与首页共用条目布局，分类标签下展示原站摘要与高亮，头像/作者/时间在下方，已看在右上，统计/稍后再看/菜单靠右；保留命中楼层链接与分页，搜索阅读卡与网格设置已废弃 |
| 帖底推荐 | 推荐与相关主题采用首页同款 Material 3 原生条目；「页面 → 主题列表 → 列表样式」可统一选择美化后或美化前（原站样式），即时生效 |
| 正文预览 | 首页自动正文预览已废弃；从菜单「预览」手动打开带 betterLD 样式和树状回复的真实 LinuxDo 网页，关闭卸载 |
| 作者身份 | 保留原帖作者 ID 与头像；回复数、最后活动时间等元信息以紧凑形式保留 |
| 分区标识 | 保留分类与标签的原色、链接和原站交互 |
| 视觉增强 | 可调背景图片 + 页面遮罩 + 卡片模糊，跟随站点主题自动切换明暗配色；原站编辑器、弹窗、按钮、表单/下拉、聊天与 AI 输入、徽章/登录/关注流统一 M3 材质与控件状态，保留原站交互和尺寸；浮动工具使用内联 Material SVG |
| 主题回复 | 主题页默认以真实回复关系的多级树代替按时间排列的原生回复流：父回复包含子回复，保留完整正文、图片与原站嵌入内容（B 站等 iframe 播放器）、可折叠，跳楼后以目标读段双向续载，接近顶部约 5 条可见回复时提前加载前段，向下继续加载后续回复，上方插入保留阅读位置；全部系统事件按楼号显示在主题直属层，复用原站文案与图标，不接回复连线、不生成分支收放控件；快问快答主题复用原站解决方案按钮、采纳标记与主帖摘要；默认同时显示昵称与用户名，可在设置中改为仅显示其中一种；每项名称最多显示约 12 个汉字宽度，超出单行省略，悬停可查看完整名称；完整显示原站上传和字母头像，保留日期并追加会更新的相对时间；点击头像打开原站用户卡片；每层以一个 Material 按钮展示回应图标与数量：点击图标点赞、点击数字在树内查看原站回应人名单（支持分页），悬停或长按选择其他回应（选择器中也可查看名单），提交后按原站返回数据更新状态；已选中某个回应时再次点击即取消当前回应；楼内已有的 Boost 按原站形态显示在该楼操作栏下方（无 Boost 则不显示）；没有 Boost 的楼层用操作栏的 Boost 按钮、已有 Boost 的楼层用列表末尾的火箭按钮，就地在同一楼下方展开原站同款编辑器（当前用户头像 + 文本域 + 提交/取消，尺寸与素材继承原站插件 CSS），回车提交、Escape 或取消关闭；提交后新气泡立即出现在该楼 Boost 列表里；另提供复制链接、更多操作和回复入口；其他菜单或编辑器自动定位对应楼层，树内正文与 Boost 共用原站 `PostCookedHtml` 组件及已注册的客户端增强：callout 折叠、剧透点击显示、hashtag 图标、代码块复制/全屏与语法高亮、图片灯箱、引用展开看被引用帖全文、长引用限高折叠；之后可返回树视图。 |
| 导航 | 主题标题沿用原帖链接语义，保留右键、Ctrl/Cmd 点击、键盘新标签页等浏览器原生操作 |
| 收藏库与已读 | 本机「稍后再看」「收藏」双分组，收藏支持文件夹，条目按日期分组并保留作者、保存时间与收藏楼层；树内原站书签成功后可镜像到本机收藏，本机删除不操作原站书签。浏览历史使用 LinuxDo 原生「已读」，沿用首页列表样式 |
| 空搜索补充 | 站内确认无结果时，可选 Bing / DuckDuckGo 追加 `site:linux.do`；主题 ID 去重、站外与非主题过滤、标明来源；默认关闭，启用先授予引擎访问权限 |
| 浏览器 DoH | 「高级 → 浏览器网络」定位 Chrome 安全 DNS / Firefox 基于 HTTPS 的 DNS；保持浏览器现有配置，由用户自行选择 |

可视设置项与取值区间（越界值在读取时即被 `clamp` 到区间内）：遮罩不透明度 0–0.8、背景模糊 0–32px、卡片不透明度 0.55–0.95。参数通过 CSS 自定义属性（`--betterld-mask-opacity`、`--betterld-background-blur`、`--betterld-card-opacity`）注入页面，参数值与样式消费分离。

首页、搜索与帖底推荐均保留原生条目；列表样式可统一选择「美化后／美化前（原站样式）」，切换不影响顶栏与壁纸。搜索阅读卡、网格/缩放和旧布局设置已废弃，旧存储设置会被忽略。搜索保留原生摘要与命中高亮，摘要显隐设置放在「页面 → 搜索」。顶栏默认与毛玻璃模式在所有页面共用渐变模糊，透明与不透明模式按选择显示。首页列表与主题阅读区的宽度上限统一为 1420px；桌面帖子阅读区采用 90% 宽度并受该上限及侧栏/时间轴可用空间约束。首页欢迎区、提示、筛选导航与列表左右对齐，帖子标题、回复树和页底模块共用阅读轨道，按整个浏览器视口的物理中线居中；窄窗口时间轴独占一行。新/更新话题提示采用紧凑居中胶囊；网页预览铺满弹窗标题与底部操作之间的区域。参数在 `betterld.config.js`。

## 设计要点

**参数集中且冻结。** 所有运行参数与设置默认值集中在 `betterld.config.js`，以 `Object.freeze` 发布的单一 `globalThis.BETTERLD_CONFIG` 对象提供：路由轮询周期、设置同步防抖、列表宽度、回复加载节奏、壁纸模式与内置图库、设置项上下限。不通过环境变量注入参数，也不存在第二份默认值。

**纯精确覆盖，不改站点数据。** LinuxDo 原有 DOM 只做精确覆盖和可恢复替换；原生列表节点由 Discourse 管理，路由切换不留下替代网格。插件只影响当前用户的浏览体验，不改变服务端数据，也不改变其他用户看到的内容。

**列表元信息零额外请求。** 作者、头像、活动时间与统计只取自站点已下载的预载/Discourse 模型。缺字段保持缺失；列表滚动、停顿与悬停都不读取首帖正文，也不为作者补发主题 JSON。原站行和链接保持原位，插件只追加幂等信息栏，筛选、字号和显隐设置继续生效。

**手动预览真实网页。** 菜单「预览」或主题打开方式中的「抽屉」加载同站主题 iframe，不再以 cooked/Markdown 拼首帖；插件自有预览内使用 betterLD 样式与树状回复，标题、树与原帖回复共用居中布局。树楼层和 Boost 正文复用原站 PostCookedHtml 及全部已注册客户端装饰，包含惰性视频、引用、代码与灯箱；其他 iframe 不接管。关闭时卸载 iframe 并返回触发链接焦点。

**帖子导出。** 帖底「导出」（页底未装载时位于标题块）支持 HTML／Markdown／分享图片（PNG），范围包括主帖、全部回复、已加载回复及数字楼层范围，例如 `1,3-8`，网页预览内也可使用。PNG 按配置拆分长图；已加载范围只消费已有内容，不补请求。转换代码来自 [Linuxdo-Export-Markdown](https://github.com/kai-wei-kfuse/Linuxdo-Export-Markdown)，完整 MIT 声明保留在 `src/topic-export.js` 并随包分发。只在用户操作时读取缺少的正文，复用现有限速队列。HTML 导出对话框新增「HTML 资源保存方式」：默认「完全离线内嵌」，可切换为「远程引用」。远程模式保留头像和正文媒体的绝对地址，不下载资源、不申请归档权限；打开需联网，原帖删除或资源失效后媒体可能无法显示。两种模式共用头像与回复连线，外部播放器仍不支持导出，文件均不执行脚本。完全离线模式为单文件归档，内嵌作者头像、正文图片/表情、直链音视频与字幕、附件及样式资源；树视图保留父子回复连线，原帖视图保持平铺。首次遇到资源域名时，在「高级 → 导入与导出 → HTML 导出离线归档」点击授权，返回帖子重新导出；只申请列出的精确域名。下载失败、缺失权限、需要重定向、超出大小限制，或遇到 B 站/YouTube 等不能直接归档的外部播放器会明确停止，不生成缺内容的文件。默认单资源最多 32 MiB，最终 HTML 最多 256 MiB，参数集中在根目录 `betterld.config.js` 的 `topicExport`；分段流媒体播放列表、无法确认自包含的 SVG/CSS 也会明确停止。成功保存后，断网或原帖删除均不影响内嵌内容；出处与导航链接点击跳转仍需联网，文件不执行脚本。Markdown 仍保留远程媒体链接。

**树状回复保留读段。** 初始显示主帖与第一层回复；父楼按钮收放其子分支，长竖线上的后续同级按钮只控制该点之后的同级回复。连线组和父分支按钮共同高亮，后续同级按钮单独高亮；收放不隐藏父楼正文与操作。深链及主动跳楼只展开到目标的必要路径，以目标连续读段向前／向后每批加载 20 条，不再拼接不相连的首批缓存；向上预载提前至约 5 条可见回复。补父和几何重测保留当前读段；初始定位统一走跳楼流程，布局完成后只做一次即时滚动补偿。系统事件允许合法空正文，使用原站事件组件并排除回复连线与普通回复收放计数。新回复和 Boost 直接挂载原站正文组件，挂载后再测连线，正文／图片／尺寸通知合并到每帧一次，减少重复排版。

**请求与缺帖恢复。** 所有楼层读取复用同一串行限速队列。遇到限流或站点质询，等待从 10 秒起按 10、20、30 秒递增，成功后重置；原站 `Retry-After` 更长时遵从原站要求，未到期的旧冷却保持截止时间。分页遗漏正文时重新核对楼层列表，再定点重读仍存在的缺失帖子；仍缺正文则明确显示重试入口，系统事件不会被误判为普通回复缺失。

**背景来源三选一，失效即回退。** 支持网站随机图（`picsum.photos` 按日期播种，每天固定一张）、内置图库（8 张，含 NASA、BML2019 等）和用户自定义（远程 URL 或本地图片）。本地图片经 canvas 压缩为 JPEG（quality 0.9，最长边 2560 × 1440，≤ 8MB）后存入 `browser.storage.local`。任何来源失效时回退到明暗对应的内置渐变，页面保持可用。

**配色跟随真实主题状态。** `content.js` 通过 `MutationObserver` 监听 `documentElement` / `body` 上的 `class`、`style`、`data-color-scheme`、`data-theme`、`data-theme-name` 变化，并监听系统 `prefers-color-scheme`，据此切换背景、遮罩、卡片与文字的对比度。

**幂等与自恢复。** 内容脚本以 `globalThis.__betterldContentScriptActive` 防重入；DOM 变更由 `MutationObserver` 触发，插件自身写入期间置 `mutating` 标志避免自激循环，写入结束经 160ms 防抖同步。

**双浏览器单份清单。** 一份 MV3 `manifest.json` 同时覆盖 Chrome 与 Firefox 桌面端（`browser_specific_settings.gecko`，`strict_min_version: 109.0`）；运行时以 `globalThis.browser || globalThis.chrome` 适配扩展 API 差异。

## 目录结构

```
CHANGELOG.md           按版本归档的更新日志
manifest.json          Chrome / Firefox 共用的 Manifest V3 配置
betterld.config.js     运行参数与设置默认值（唯一参数文件）
src/content.js         原生列表增强、搜索结果、网页预览、树状回复
src/content.css        Material 3 风格 Token、原生列表、原生搜索结果、背景效果
src/topic-library.js/.css 本地双分类收藏与 Material 3 面板
src/external-search.js 可选引擎 URL 与主题结果解析、去重
src/options.html       设置页（同时作为工具栏弹窗）
src/options.js         设置读写、壁纸选择与本地图片压缩
src/options.css        设置页样式
```

## 本地加载

```bash
npm run check   # JavaScript 语法检查
npm run package # 原位更新 dist/betterLD/
```

- **Chrome**：打开 `chrome://extensions`，启用开发者模式，加载已解压的扩展程序 → 选择 `dist/betterLD/`。
- **Firefox**：打开 `about:debugging#/runtime/this-firefox` → 临时载入附加组件 → 选择 `dist/betterLD/manifest.json`。

源码可直接加载，交付包使用固定目录 `dist/betterLD/`；`npm run package` 只拷贝文件，不编译源码。更新后重新载入实际加载该目录的扩展，再刷新已打开的 LinuxDo 标签页；仅覆盖磁盘文件不会更新 Firefox 已驻留的内容脚本与样式。

## 范围与不变量

- 覆盖范围为 Chrome / Firefox **桌面视口**；移动端不属于首版适配范围。
- 列表增强覆盖原生主题列表、搜索结果及帖底推荐/相关主题；美化前恢复原站条目，壳层视觉全站生效，搜索摘要和分页独立设置。
- 不把用户 Trust Level 当作分区信息；不用帖子内容替换作者身份信息。
- 领域术语与不变量见 `CONTEXT.md`，开发约定见 `AGENTS.md`。
- [实际功能、接口与架构审计](docs/architecture-interface-audit.md)：功能入口、公开方法、消息/事件、数据流及有源码依据的收敛建议；第 11 节记录已实施的行为等价收敛与保留项。
