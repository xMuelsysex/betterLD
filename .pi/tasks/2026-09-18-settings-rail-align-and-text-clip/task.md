# 2026-09-18 设置面板：左侧图标居中 + 选项文字被截断

## 目标与决策

主人要求：① 面板左侧竖列图标对齐；② 面板里有的选项文字显示不全。

实测（Playwright 打开 `src/options.html`，1280×820，窗口 1000×900，行宽 683）：

- 根因 1（图标）：`.settings-rail__list` 的 `width` 没算自身左右 1px 边框，内容盒只有 38px，
  而 `.settings-rail__item` 用 `padding: 0 12px`，图标 20px 就变成「左 12px / 右 6px」，
  折叠态方块里图标偏右、激活圆形也是 38×40 的椭圆。修法：列表宽度补 2px 让内容盒正好 40px，
  图标内边距按 `(40 - 20) / 2` 计算 → 左右各 10px，方块 40×40 正圆。
- 根因 2（文字截断）：`.settings-field__right` 同时有 `flex: 0 1 auto`（可被压缩）与 `max-width: 62%`。
  行内左列 `.settings-field__left` 的 flex base 是说明文字的 max-content（很长），
  于是 flex 按比例压缩右列：`话题排序方式` 的控件在 683px 的行里只剩 92px，`搜索结果模式` 只剩 122px；
  而 `主题模式` 的 5 段被 62% = 423px 卡住，每段 83px。
  控件自身是 `overflow: hidden` + `text-overflow: ellipsis`，于是「跟随 LinuxDo」「Material 3 卡片」
  「最新回复」「仅使用浏览器缓存」等标签被省略号截掉。
  修法：右列 `flex: 0 0 auto`（保持控件自身宽度）+ `max-width: 100%`（只在行比控件还窄时兜底），
  行 `flex-wrap: wrap` + 左列 `flex: 1 1 280px`：控件放不下时整行换行（控件自己占一行、贴右对齐），
  放得下时说明文字换行让位。≤760px 的列方向布局补 `flex: 0 1 auto`，避免 `flex-basis` 变成高度。
- 不引入新参数；几何全部落在 `src/options.css`，`settings.js` / `options.js` / config 未动。

## 计划

1. 量出根因（图标左右间距、每个分段控件与标签的 client/scroll 宽度、行溢出）。
2. 只改 `src/options.css`：rail 两处 + 设置行四处（行 wrap、左列 basis、右列 flex/max-width、≤760px 覆盖）。
3. 全量复核：所有面板 + 所有条件字段强制显示，逐视口检查截断与溢出；再与「改动前 CSS」做几何 diff，确认没有夹带其他变化。

  未再跑 Orca 实机（该改动不涉及站点 DOM，且实机需要预热 Cloudflare 质询）。

## 结论

- 图标在折叠方块内水平居中（10/10，40×40），激活项为正圆。
- 设置项文字不再被挤压截断：控件保持自身宽度，说明文字换行让位；放不下时控件独占一行贴右。
- 遗留：低于 1000px 视口宽度时，5 段以上的分段控件仍可能省略末位标签（兜底路径），按桌面端定位未再处理。
