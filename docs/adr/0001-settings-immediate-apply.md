# 1. 设置改动即时生效

- **Status**: Accepted
- **Context**: betterLD 的设置项已从首版 6 项增长到 76 个以上标量控件加多个结构化编辑器，分布在多个分组；原设置界面要求点击「保存设置」才写入存储。按 BewlyCat 的设置界面重做时，BewlyCat 不提供提交动作，改动直接写入；而 betterLD 运行时已经通过存储变化监听即时应用设置，保存按钮只是额外一层确认。
- **Decision**: 设置窗口不提供提交按钮，任何控件变化立即写入存储并作用于当前页面。恢复默认、导入、清空搜索历史等破坏性操作保留独立确认。
- **Consequences**: 更容易：不需要维护「未保存」状态与脏值比较，设置项继续增加不增加保存复杂度；用户改完立刻看到效果；运行时只有一条生效路径（存储变化 → 应用）。更难：误操作立即生效，回退只能依赖单项恢复或恢复默认；跨多项批量调整没有统一取消点；滑块类连续变化控件需要在写入时机上做约束，避免写入风暴。
